## Overview

Cyberpunk 2077 IFP Camera Config is a companion configurator for the Improved First Person Camera mod, providing a clean interface to adjust body visibility percentages, camera position offsets, FOV values for each game mode, and head/body movement thresholds without manually editing the mod's nested configuration files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cyberpunk 2077 IFP Camera Config** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Body Visibility** | Adjust body mesh visibility percentage in first-person view |
| **Camera Offsets** | Fine-tune camera position X/Y/Z offsets for each game state |
| **FOV Per Mode** | Set independent FOV values for on-foot, vehicle, and ADS modes |
| **Movement Thresholds** | Configure head bob and body sway sensitivity independently |
